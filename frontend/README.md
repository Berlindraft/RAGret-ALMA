# RAGret frontend

React + Vite, React Flow, Lucide, Motion, and locally bundled fonts. A simple light workspace for a persistent context graph, decision register, timeline, sources, and people/constraints.

See the [project README](../README.md) for setup and features. The dev server proxies `/api` to port 3005. Ctrl/Cmd+K focuses the graph question field. The graph supports pan/zoom, draggable cards, evidence on links, and a focused or full-workspace view.
